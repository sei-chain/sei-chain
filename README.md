This is the GitHub home of Sei Wallet, a self-custody desktop application for the Sei blockchain built by Sei Wallet Labs Inc. It signs `0x` transactions natively, keeps read-only access to legacy `sei1` addresses, stakes and unbonds inside the app, and connects to a Ledger when you want the keys off the machine. The Windows, macOS and Linux builds below are the current release.
